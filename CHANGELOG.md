# Changelog

## 0.1.0

First preview of the self-hosted Byturn workspace.

- Studio projects, team accounts and explicit project grants.
- Revocable review links with no client signup required.
- Multi-image versions, artwork annotations, requests for changes, final approval and original downloads.
- React design-system catalog with English and Brazilian Portuguese, and light and dark themes.
- A browser-based portfolio demo using the review UI and fictional assets.
