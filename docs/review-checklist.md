# Owner review checklist / identity and DS v1

This is the review handoff for a proposed v1, not a request to approve a production SaaS.

## Identity

- Master lockup geometry and visible symbol-to-n proportion match the approved asset.
- Paper, ink and electric-yellow applications remain legible on their backgrounds.
- Clear space and minimum sizes are proposed usage rules; approve or adjust them explicitly.
- Voice, hierarchy and misuse guidance are useful in actual design work.

## Foundations

- Outfit hierarchy, semantic roles, spacing and radius feel coherent at the chosen density.
- Orbit complements preserve transparency and light-mode multiply; text is separate.
- The light selected review card has a perceivable fill and boundary.
- All five named control sizes are inspectable; badge/avatar/symbol anatomy is documented separately.
- Focus, error, selected and disabled states are distinguishable beyond hue alone.

## Components and specimens

- Inspect actions, fields, native choices, searchable choices, overlays, feedback and review compositions.
- Try Tab/arrows/Enter/Escape, disabled choices, pending confirmation and a failed action.
- Compare light/dark at desktop and mobile widths; test Portuguese text expansion.
- The studio/client specimen communicates the intended boundary without implying real authorization.
- Upload/WebP examples are explicitly local/planned; no conversion or cloud upload is claimed.

## Reference-derived additions

- Inspect search/clear, calendar date, searchable picker, multi-select, checklist, filter chip and confirm dialog.
- Read the pinned Kitsu source evidence if a pattern's purpose is unclear.
- Existing native selection is reused rather than duplicated under a new label.

## Downloads

- Download the ZIP and inspect SVG/PNG masters, Outfit/OFL, foundation tokens, source/API docs and provenance.
- Check the source API against the intended future product needs.

Remaining decisions belong to the owner: usage-rule refinements, visual polish and whether to continue the product after the reference walkthrough. No full Figma library, npm publication, backend migration or production deployment is claimed by this delivery.
